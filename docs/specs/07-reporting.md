# 07 — Reporting

## Parcours
1. Accueil : annonceur dans une liste (ajoutés par l'admin + ceux de l'ad server si API, sinon démo). Absent : « Demander l'ajout à l'admin » (cloche de l'admin : « Ajouter » / « Refuser »).
2. « Espace report » : templates par défaut (« Check de mise en ligne », « Daily report aux régies », « Tableau croisé »), puis templates de l'agence ; « Prompt de rapport CM360 (sans API) ».
3. « Campagne et période » → « Valider » : la section se réduit, le tableau de bord apparaît. Sans API : import d'un export de rapport CM360.

## Templates
- **Check de mise en ligne** : KPI, statut par régie et emplacement, mode d'achat (CPM → impressions, CPC → clics), plan lié pour le rythme (prévu à date / livré, < 90 % en retard, > 110 % en avance, projection, budget estimé), Excel.
- **Daily report aux régies** : un bloc par régie, carnet d'adresses, calendrier, aperçu, programmation (CM360 envoie ; Adform : à programmer dans Adform), pause / reprise / modification / suppression.
- **Tableau croisé** : dimensions (dont gabarits de nommage), métriques, filtres, comparaison de périodes, vues enregistrées, graphique, Excel.

## À trancher
- **D5** : mises en forme Excel alignées sur les modèles réels de l'agence (à fournir).
- Templates d'agence plus riches (colonnes, onglets, logo).
